config/config.yaml drives every stage. python main.py --stage all runs them in order; each stage can also run alone.

Each stage writes artifacts that the next one reads, so any stage can be re-run without redoing the earlier ones. Evaluation reads the saved predictions and test set; serving reads the saved models.
