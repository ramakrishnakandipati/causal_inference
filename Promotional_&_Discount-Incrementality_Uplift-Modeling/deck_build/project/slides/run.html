Documentation · Run and extend

How to run it, and where to go next

pip install -r requirements.txt
python main.py --stage all
python main.py --stage serve-api
python main.py --stage serve-ui
python scripts/capture_screenshots.py flows
python main.py --stage test

Stages: data, train, evaluate, plots, screenshots.

Smoke run on 15,000 guests: add --quick. CPU only: add --no-gpu.

config/ data/ src/ api/ ui/ scripts/ tests/
outputs/ models · plots · logs · screenshots

Suggested next steps

  • Re-run on real CRM data with a randomized holdout for evaluation
  • Test the points offer in a live experiment to replace the modelled arm
  • Repeat across seeds and add significance tests between estimators
  • Monitor propensity drift and the calibration of the intervals over time

Suggestions only: none of these has been done in this project.

The repository is organized so that each stage can be re-run from the artifacts of the earlier ones. The README documents every stage, embeds the plots and screenshots, and lists the limitations.
